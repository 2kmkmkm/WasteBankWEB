# WasteBank 🌍  
폐기물 수거 프로세스를 디지털화한 글로벌 협업 하이브리드 앱

> World Friends Korea ICT 봉사단 프로젝트  
> 국제학술대회 **ICICT 2024 논문 발표 프로젝트**


## 📌 Overview
WasteBank는 **인도네시아 현지의 폐기물 처리 문제를 해결**하기 위해 개발된  
안드로이드 기반 **하이브리드 웹앱 서비스**입니다.

React 기반 웹을 React-Native 앱의 **WebView**에 연동하여 구현하였으며,  
현지 주민·수거인·관리자 **3가지 사용자 역할**에 따라  
각기 다른 UI와 기능을 제공하는 구조로 설계되었습니다.

본 프로젝트는 **실제 현지 클라이언트의 요구사항을 직접 수렴**하여 기획·개발되었고,  
개발 결과를 바탕으로 작성한 논문이 **국제학술대회 ICICT 2024**에 채택·발표된  
글로벌 협업 프로젝트입니다.

## 🧯 Troubleshooting
### TypeScript 초기 도입 어려움
- 상태 관리, axios 응답, props 타입 정의에서 잦은 타입 에러 발생  
→ 공식 문서 및 오픈소스 참고를 통해  
  타입 정의 패턴을 학습하며 점진적으로 해결

### 요구사항 변경에 따른 리소스 낭비
- 클라이언트 요구가 수시로 변경되는 문제 발생  
→ 재사용 가능한 컴포넌트 구조 설계  
→ Notion을 통해 변경 이력 명확히 공유

### CORS 문제로 인한 API 통신 실패
- 프론트엔드 프록시 설정 및  
  백엔드와 협업하여 `Access-Control-Allow-Origin` 헤더 수정  
- axios 인스턴스를 분리해 인증 및 에러 처리 일관성 확보
